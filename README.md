# HappyLulu

[English](README.en.md) · [영어 사이트](https://happylulu.cy-choi-lulu.chatgpt.site/en/)

<img src="Resources/HappyLuluIcon.png" width="120" alt="HappyLulu 웃는 시계 아이콘">

맥의 첫 잠금 해제로 출근을 기록하고, 메뉴바에서 퇴근까지 남은 시간을 확인하는 룰루랩 동료용 앱입니다. 회사의 공식 근태 시스템이나 급여용 증빙은 아닙니다.

**현재 배포: 1.5.2 build 10 · macOS 13 이상 · Apple Silicon 권장**

[소개·다운로드·설치](https://happylulu.cy-choi-lulu.chatgpt.site/) · [릴리즈 노트](RELEASE-NOTES.md) · [실제 내부 시험](https://github.com/young221718/happylulu-app/issues/4)

## Windows판

Windows 10/11 x64용 별도 트레이 앱을 추가합니다. 출퇴근·반차·로컬 기록·별도 설정과 한국어/영어를 지원하며 캘린더 동기화는 현재 macOS 전용입니다. 설치와 빌드는 [Windows 안내](windows/README.md)를 참고하세요. Mac과 Windows 기록은 서로 동기화하지 않습니다.

## 설치하고 시작하기

1. 사이트에서 DMG 또는 ZIP을 받습니다. 기존 앱이 실행 중이면 메뉴의 **종료**로 먼저 닫습니다.
2. 앱을 `Applications` 또는 `~/Applications`로 옮기고 실행합니다. 이전 앱과 같은 위치에서 교체하면 중복 실행을 피할 수 있습니다.
3. 메뉴바의 웃는 시계 아이콘을 누릅니다. 이미 출근했다면 **출근 시각 입력**에서 시각과 근무 유형을 저장합니다.
4. **설정**을 열어 근무·휴게시간, 로그인 시 자동 실행, 캘린더 반차 인식을 조정합니다. 언어에서 시스템 언어·한국어·영어를 선택할 수 있습니다.

첫 실행에는 로그인 자동 실행 등록을 시도하며 macOS 승인이 필요할 수 있습니다. **설정 → 일반 → 로그인 시 자동 실행**에서 끌 수 있고, 이후 사용자가 끈 설정을 다시 켜지 않습니다.

이번 버전은 **수동 설치 전용**입니다. 자동 업데이트 서비스는 보류 상태이며 설정의 업데이트 제어가 비활성화되어 있습니다. 향후 자동 업데이트를 활성화한 앱이 나오면 그 앱으로도 한 번 수동 교체해야 합니다. 자세한 준비 상태는 [UPDATES.md](UPDATES.md)와 [이슈 #3](https://github.com/young221718/happylulu-app/issues/3)에 있습니다.

현재 Developer ID 서명·Apple 공증은 완료하지 않았습니다. 브라우저 다운로드 후 첫 실행은 사용자 확인이 필요하며, 회사 관리 맥은 회사의 설치 정책을 따릅니다. Universal 파일에는 Intel 실행 파일도 있지만 Intel 실기기 시험은 차후 진행합니다.

## 메뉴바는 오늘, 설정 창은 앱 관리

| 화면 | 할 수 있는 일 |
| --- | --- |
| 메뉴바 | 퇴근 카운트다운, 오늘 출근·퇴근 시각, 출근 시각·근무 유형 수정, 오늘 쉬는 날, 최근 잠금 해제 감지 |
| 별도 설정 창 | 근무·휴게시간, 로그인 시 자동 실행, 최근 기록 7건, 캘린더 반차 인식, Calendar 창 열기, 업데이트 상태 |
| Calendar 창 | 시스템 계정 연결 안내, 회사 서버 주소 복사, 캘린더 선택, 첫 미리보기, 동기화·충돌 상태 |

Finder에서 실행 중인 앱을 다시 열면 설정 창이 열립니다. **오늘 쉬는 날**은 확인 후 오늘 기록을 지우고 자동 출근 기록을 멈춥니다. 출근 시각을 직접 입력하면 다시 시작합니다.

## 출근과 퇴근 계산

기본 설정은 근무 8시간 + 휴게 1시간입니다. 허용 구간의 종료 시각은 해당 분 전체를 포함합니다.

| 근무 유형 | 출근 허용 구간 | 계산 예시 |
| --- | --- | --- |
| 일반 | 08:00~10:00 | 09:00 출근 → 18:00 퇴근 |
| 오후 반차 | 08:00~10:00 | 09:00 출근 → 13:00 퇴근 |
| 오전 반차 | 13:00~15:00 | 13:00 출근 → 17:00 퇴근 |

- 일반 근무는 **매달 마지막 금요일에 2시간 조기 퇴근**합니다. 기본 설정의 09:00 출근은 16:00 퇴근입니다. 공휴일 대체·이월은 하지 않습니다.
- 반차는 휴게 없이 4시간 근무하며 마지막 금요일 단축을 중복 적용하지 않습니다.
- 출근은 하루의 첫 유효한 잠금 해제만 저장하고 이후 해제로 덮어쓰지 않습니다. 직접 수정한 시각도 유지합니다.
- 출근 시각으로 오전 반차를 판단하고, 오후 반차는 수동 선택 또는 허용한 캘린더의 명확한 제목으로 판단합니다. **수동 근무 유형이 자동 판단보다 우선**합니다.
- 캘린더 반차 인식은 접근 가능한 모든 캘린더의 제목을 읽습니다. 공유 캘린더의 다른 사람 반차가 섞이면 수동으로 지정하거나 자동 인식을 끄세요. 이 기능은 일정을 수정하지 않습니다.
- 남은 시간은 실제 시각 차이로 약 15초마다 갱신합니다. 절전·점심 잠금 동안에도 시간이 흐릅니다.

## 캘린더 연결은 필요할 때

**설정 → 캘린더 → HappyLulu Calendar 열기**에서 시작합니다. 계정 로그인은 macOS 인터넷 계정에서 처리하며, 앱의 **서버 주소 복사** 버튼으로 회사 CalDAV 주소를 복사할 수 있습니다.

Calendar는 다우오피스와 Google의 일반 일정 추가·수정을 양방향으로 맞추는 베타 기능입니다. 양쪽에 빈 테스트 캘린더를 만들고, 첫 미리보기를 확인한 뒤 동기화를 시작하세요. 삭제·반복·초대·알림 등 지원하지 않는 일정은 자동 처리하지 않습니다. 실제 웹 캘린더 반영은 별도로 확인해야 합니다.

[계정 연결 순서, 지원 범위와 충돌·복구 안내 → CALENDAR.md](CALENDAR.md)

## 기록과 감지의 범위

출퇴근 기록은 `~/Library/Application Support/AfterSix/state.json`에 로컬로 저장합니다. 이전 AfterSix 저장 경로와 앱 식별자를 유지하므로 교체할 때 기록을 초기화하지 않습니다. 네트워크 수집이나 키보드·화면 수집은 하지 않습니다. 캘린더 연결 상태는 별도의 로컬 저장소에 있으며 인증은 macOS가 관리합니다.

앱이 꺼져 있던 동안의 출근은 복원하지 않습니다. 절전 복귀·화면 켜짐·세션 전환만으로 출근을 만들지 않고, 회사 위치나 Wi-Fi도 판별하지 않습니다. 집에서 먼저 맥을 해제하면 그 시각이 기록될 수 있습니다. 첫 로그인이나 허용 구간 밖에서 감지되지 않으면 직접 시각을 입력하세요.

현재 감지는 `com.apple.screenIsUnlocked` 분산 알림에 의존합니다. macOS 업데이트 후 실제 잠금 해제와 로그인 자동 실행을 확인해야 합니다. 저장 시각·시간대와 맥의 현재 날짜를 사용하며 야간 교대근무나 기기 간 동기화는 지원하지 않습니다. 손상되거나 지원하지 않는 기록 파일은 덮어쓰지 않고 오류를 표시합니다.

## 개발·검증·배포

macOS 13 이상, Swift 6과 기존 Command Line Tools를 사용합니다. 내부 `AfterSix`/`AfterSixCore`, 번들 ID `local.chanyoung.AfterSix`는 호환성을 위해 유지합니다.

```sh
bash scripts/build-app.sh
swift run --build-system native AfterSixChecks
swift run --build-system native CalendarSyncChecks
swift run --build-system native CalendarSyncServiceChecks
```

앱은 `dist/HappyLulu.app`에 생성하며 로컬 ad-hoc 서명을 합니다. 현재 Command Line Tools 환경에서는 기존 native 빌드 엔진을 명시합니다. 해당 옵션은 향후 제거될 수 있어 Swift 환경 변경 시 확인해야 합니다.

```sh
bash scripts/package-release.sh
~/Applications/HappyLulu.app/Contents/MacOS/HappyLulu --status
```

패키징은 `dist/releases/<버전>-build<빌드>/`에 Universal DMG·ZIP·노트·SHA-256을 만들고 같은 버전 폴더를 덮어쓰지 않습니다. 산출물·개인 기록·인증정보는 Git에 넣지 않습니다. 아이콘은 [BRANDING.md](BRANDING.md), 서명·업데이트 준비는 [UPDATES.md](UPDATES.md)를 참고하세요.

자동 검사·빌드·아카이브 검증은 실제 기기 시험과 다릅니다. 설치 후 기록 유지, 실제 잠금 해제, 로그인 실행, 캘린더 서버 왕복은 [내부 시험 #4](https://github.com/young221718/happylulu-app/issues/4)에서 추적합니다. 마지막 실행 결과와 미검증 범위는 [VALIDATION.md](VALIDATION.md)에 기록합니다.
